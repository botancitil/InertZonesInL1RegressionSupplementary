1. Online Inertness Condition Test

Upon observing an arrival \((\hat{\mathbf{x}}, \hat{y})\), testing whether the current optimal regression parameters \(\beta^*\) remain unchanged requires evaluating the updated dual vector \(\hat{u}_F\). Recalculating the LP is avoided whenever \(-1 \leq \hat{u}_F \leq 1\): 

# Gemini 09/17/26
import numpy as np

def is_arrival_inert(u_F_star, X1_inv, beta, x_hat, y_hat):
    """
    Tests if an arrival (x_hat, y_hat) is inert under current basis parameters.
    """
    # 1. Determine orientation relative to current hyperplane
    y_pred = beta[0] + np.dot(x_hat, beta[1:])
    if y_hat > y_pred:
        I_diag = 1.0   # Above
    else:
        I_diag = -1.0  # Below

    # 2. Update fitted duals: u_hat_F = u_F_star - I_diag * (1, x_hat) @ X1_inv
    augmented_x = np.concatenate(([1.0], x_hat))
    delta_u = I_diag * np.dot(augmented_x, X1_inv)
    u_hat_F = u_F_star - delta_u

    # 3. Check dual feasibility [-1, 1]
    inert = np.all(u_hat_F >= -1.0 - 1e-9) and np.all(u_hat_F <= 1.0 + 1e-9)
    return inert, u_hat_F

2. Polyhedral Facial Decomposition (SciPy & Qhull)

To reconstruct the cross-sectional polytopes of the inert zones from the inequality systems \(A x \le b\), the bounded polyhedron is converted from its external halfspace representation to its internal vertex representation using scipy.spatial.HalfspaceIntersection: 

# Gemini 09/17/26
import numpy as np
from scipy.spatial import HalfspaceIntersection, ConvexHull

def compute_inert_cross_section(halfspaces, interior_point):
    """
    halfspaces: Array of shape (M, d + 1) in the form [A, -b] for Ax <= b
    interior_point: Known feasible point (e.g., barycenter of the simplex)
    """
    hs = HalfspaceIntersection(halfspaces, interior_point)
    vertices = hs.intersections

    # Derive facet incidence using ConvexHull on the computed vertices
    hull = ConvexHull(vertices)
    return vertices, hull.simplices
